# IRANYekan Fonts

این دایرکتوری شامل فایل‌های فونت **IRANYekanXFaNum** برای استفاده محلی است.

## فایل‌های موجود

- `IRANYEKANXFANUM-REGULAR.TTF` - وزن معمولی (400)
- `IRANYEKANXFANUM-LIGHT.TTF` - وزن سبک (300)
- `IRANYEKANXFANUM-MEDIUM.TTF` - وزن متوسط (500)
- `IRANYEKANXFANUM-BOLD.TTF` - وزن ضخیم (700)

## توجه

تمام فایل‌های فونت موجود مستقیماً از `styles.css` استفاده می‌شوند. حذف هر فایل باعث مشکل نمایش فونت خواهد شد.

## اندازه کل

تمام فایل‌های فونت: ~333 KB

## استفاده

پروژه خودکار این فایل‌ها را بارگذاری می‌کند. نیازی به کنفیگ اضافی نیست.
